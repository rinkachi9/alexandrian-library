# Macroeconomics

How the economy behaves as a whole: output, growth, inflation, employment, public debt and policy. This subfield belongs to [Economics](../README.md). The first note covers gross domestic product, the main measure of output that other macroeconomic ratios, such as public debt relative to GDP, are built on.
