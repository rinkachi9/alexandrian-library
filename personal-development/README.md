# Personal development

Deliberate improvement of oneself: character, habits, skills and career. The [career](career/README.md) field is written, and [skills](skills/README.md) has notes on hard skills. Personal growth is planned and has no notes yet.

## Fields

- [Personal growth](personal-growth/README.md): Understanding and changing how you think, feel and act.
- [Skills](skills/README.md): Abilities that can be learned and practiced. Skills cut across many domains, so a skill note links to the note that explains the underlying knowledge instead of repeating it.
- [Career](career/README.md): Finding, getting and growing in work.
