# Skills

Abilities that can be learned and practiced. Skills cut across many domains, so a skill note links to the note that explains the underlying knowledge instead of repeating it. This field belongs to [Personal development](../README.md). Hard skills have notes. Soft skills and the general topics below are planned.

## Subfields

- [Soft skills](soft-skills/README.md): Transferable skills that apply in most roles. Planned grouping follows the three domains of the US National Research Council report on 21st century skills (2012): cognitive, interpersonal and intrapersonal. TODO: verify against the report.
- [Hard skills](hard-skills/README.md): Skills tied to a specific task, tool or profession, and usually testable.
